### Simplicity

<td align="center" width="25%">

**02**

### Structure

Organized systems and maintainable code.

</td>
<td align="center" width="25%">

**03**

### Reliability

Correctness, consistency, and thoughtful testing.

</td>
<td align="center" width="25%">

**04**

### Evolution

Continuous improvement and learning.

</td>
</tr>
</table>

### How I approach a problem

**01 — Understand**

Define the problem, its context, and its actual requirements.

**02 — Analyse**

Break complex challenges into smaller components.

**03 — Explore**

Evaluate possible technologies, solutions, and trade-offs.

**04 — Implement**

Build a practical and structured solution.

**05 — Refine**

Test, review, optimize, and improve.

> "Good engineering is not about writing more code. It is about making better decisions with the code you write."
